常用变量说明
OPENWRT_HOST OpenWrt 主路由局域网 IP（默认 192.168.1.1）
OPENCLASH_API_PORT OpenClash 外部控制端口（默认 9090）
OPENCLASH_API_SECRET 外部控制密钥（未设置留空）
OPENWRT_SSH_PASS OpenWrt SSH root 密码（用于启停服务与切换机场）
POWER_TOGGLE_MODE 启停策略（smart / service / mode）
SUBSCRIPTION_PROXY 机场订阅拉取专用代理（如 http://192.168.1.1:7890）
提示：点击「保存」后系统将立即热更新当前运行中的路由器与 Clash 连接参数；若修改了 Docker 容器对外暴露端口 (PORT) 或时区 (TZ)，建议在控制台执行 docker compose restart。

出海下载确认

分流阻断提示 直连与常规规则分流均无法访问

订阅域名直连不可达，且当前 OpenClash 规则分流未包含该订阅域名（导致直接连接被防火墙阻断）。

临时全局出海影响说明
  • 全网影响：允许后，OpenClash 将临时切换为全局代理模式（约 2~3 秒）强制走海外代理节点拉取订阅。切换期间，全屋所有连接该路由器的设备流量将短暂全部走代理出海。
  • 自动恢复：无论拉取成功与否，下载结束后将立即自动恢复为您原本的规则分流模式。
  • 替代方案：若您不希望临时影响全屋网络，可点击“取消”，并通过“上传 YAML”按钮直接导入机场配置文件。
